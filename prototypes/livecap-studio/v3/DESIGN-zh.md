# Livecap — 第三版交互设计

独立重建于 v3/。没有复用前两版布局或样式，也未改动桌面 App。

## 产品结构

1. 首次配置：独立双栏向导，领域选择 → 资料整理 → 结果确认。左侧展示术语如何影响字幕，右侧只承担当前一步。
2. 日常工作区：顶部仅字幕、知识库两项导航。启动前配置声音/语言/领域；启动后收起已确定的配置，保留暂停操作与会话记录。字幕窗口是独立区域。
3. 知识库：支持多个领域，左侧切换领域，右侧术语表，搜索和编辑在原地完成。新建走同一向导。
4. 设置：模态面板，不打断或离开当前会话；外观调整有同步预览。费用仅在会话控制区显示。

## 参考及采用的原则

- Granola https://www.granola.ai/：实际查看会议场景中的笔记窗口及独立录音指示器。借鉴会中轻量控制与工作内容分离，未照搬其界面。
- Superwhisper https://superwhisper.com/：官网展示 Modes / Vocabulary / Configuration 和分层的自定义模式。借鉴可复用领域配置与即时操作分开。
- Windows 流程 https://superwhisper.com/docs/get-started/windows：先设置向导，后系统托盘/设置的日常使用路径。Livecap 相应将首次配置移出日常导航。

## 实现与边界

纯 HTML/CSS/JS，无依赖和外部资源；约 8 秒本地生成动画、暂停/取消、多知识库切换、搜索/译法修改、JSON 导出、字幕播放/暂停、会话记录、主题/字号/透明度/双语排列/停靠模式均可操作。

顶栏统一标记设计预览，界面正文使用拟议产品文案。所有内容为样例；无 API 请求、音频采集或密钥读取。文件保存状态是产品流程模拟，实际下载仅在点击导出时发生；内存状态刷新重置。服务状态为示意。移动布局及减少动态效果均有适配。

预览地址：http://127.0.0.1:4317/v3/

## 本轮验收

在内置浏览器验证：三步向导生成、暂停/继续、跳过配置、会话启动/暂停、运行时配置收起、字幕逐步更新、设置模态面板、字号即时调整、术语搜索/编辑并保留筛选。1280 × 820 桌面及 390 × 844 窄屏已检查；窄屏 DOM 宽度与视口宽度相同，无横向溢出。JavaScript 语法检查通过。真实服务接入留在确认设计之后。

## 连续更新修正

按用户反馈移除整秒追加及每次重建记录的方式。改用 requestAnimationFrame 驱动时间、约 90 ms 的增量检查；只更新当前句的文本节点，仅在新句到达时添加段落，最多保留 12 段。暂停保留部分文字，当前阅读位置脱离底部时不强制滚动，字幕预留两行空间。主工作区不再因暂停/继续重复播放页面入场动画。浏览器连续换句检查无运行错误。
