# Livecap · 网页交互设计预览

独立静态原型。由主代理直接设计和实现；没有修改现有 App、后端或构建产物。

运行：`python -m http.server 4317 --bind 127.0.0.1 --directory prototypes/livecap-studio`
访问：http://127.0.0.1:4317

交互：领域卡片、细分方向、自定义领域、8 秒模拟生成、暂停/继续/取消、结果搜索、译法编辑、JSON 示例导出、字幕播放/暂停/重播、字号/主题/不透明度/排列/位置即时预览、存储与连接设置演示。

边界：所有资料和进度均为样例。无 API、无音频采集、无密钥输入；内存状态刷新即重置。生成后自动缓存到文件是拟议 App 行为，网页只展示该状态；用户点击导出才实际下载 JSON。

视觉参考：
- https://linear.app/ — 清晰的信息层级、低噪声工作空间
- https://www.raycast.com/ — 精简工具交互、聚焦内容的呈现

自定义的浅色灰绿工作空间、暖陶色选择态、细线图标、深色字幕舞台；不复用现有 App 组件。支持键盘焦点、原生模态框、减少动态效果偏好和窄屏布局。
